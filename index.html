01 OUR SERVICE

민원팩토리 개발 중

민원 업무에,
더 나은 여유를.

접수된 민원을 정리하고, AI로 답변 초안을 준비합니다. 공공기관 담당자가 초안을 검토·수정하고 파일로 내려받을 수 있도록, 민원 답변 작성의 흐름을 연결합니다.

민원팩토리 업무 흐름 살펴보기 ↓
사람에게 시간을 돌려주는 기술.라이트워크가 지향하는 변화입니다.

MINWON FACTORY / WORKFLOW

AI는 초안을,
담당자는 최종 판단을.

내용을 파악하고, 답변을 다듬고, 결과를 정리하는 일.
민원팩토리는 담당자의 답변 작성을 돕는 업무 지원 도구입니다.

  1. 01

    입력

    민원을 한곳에 모으고

    민원 내용을 직접 입력하거나, 엑셀·CSV 파일로 여러 건을 불러옵니다.

    직접 입력 · 파일 불러오기
  2. 02

    준비

    답변의 방향을 정하고

    AI가 정리한 민원 요약과 카테고리를 확인하고, 답변 요지와 양식을 준비합니다.

    민원 요약 · 답변 요지 · 양식
  3. 03

    초안 작성

    AI와 초안을 만들고

    민원 내용, 답변 요지와 양식을 바탕으로 답변 초안을 생성하고 진행 상황을 확인합니다.

    답변 생성 · 진행 상황 확인
  4. 04

    검토와 활용

    담당자의 답변으로 완성

    초안을 직접 수정하거나 재생성한 답변과 비교합니다. 선택한 답변은 복사하거나 엑셀·CSV로 내려받습니다.

    편집 · 비교 · 내려받기
↳

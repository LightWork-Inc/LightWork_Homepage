# LIGHTWORK 홈페이지 개발 인계

작성일: 2026-09-21. 라이트워크 회사 홈페이지의 로컬 개발을 시작하기 위한 디자인 자료와 요구사항입니다.

현재 상태는 **첫 반응형 구현 및 로컬 미리보기 완료**입니다. 헤더, 첫 화면, 민원팩토리 소개와 Contact us 준비 안내를 구현했습니다. 실제 서비스 연결, 문의 접수, 사이트 배포는 아직 구현하지 않았습니다.

## 로컬 실행

Node.js 22 이상이 필요합니다. 별도 패키지 설치 없이 실행됩니다.

```powershell
cd D:\LightWork_Homepage
npm run dev
```

브라우저에서 **http://localhost:5173** 에 접속합니다. 서버는 이 컴퓨터의 루프백 주소에만 바인딩됩니다. HTML·CSS·JavaScript 및 `assets/` 파일을 저장하면 연결된 브라우저가 자동으로 새로고침됩니다. 디자인 참고 HTML 변경도 감지하며, `dist/`와 로그 변경은 제외합니다. 터미널에서 실행한 서버는 `Ctrl+C`로 종료합니다. 서버 코드 자체를 수정한 경우에는 서버를 다시 실행합니다. 자동 새로고침은 개발 서버에만 적용되며 빌드 결과에는 포함되지 않습니다.

```powershell
npm run build
npm run preview
```

빌드 결과는 `dist/`에 생성됩니다. 빌드 결과 미리보기 주소는 **http://localhost:4173** 입니다. 빌드는 배포를 수행하지 않습니다. 포트가 사용 중이면 기존 서버를 종료하거나 PowerShell에서 `$env:PORT = '5175'`를 설정한 뒤 실행합니다.

이번 개발 세션에서 실행한 5173 서버는 백그라운드로 유지됩니다. 해당 서버의 PID는 `.preview/server.pid`, 로그는 `.preview/server.log`와 `.preview/server-error.log`에 있습니다. 재실행 전에 이 세션의 서버를 종료하려면 `Stop-Process -Id (Get-Content .preview/server.pid)`를 사용합니다.

## 구현 구조와 검수

- `index.html`: 시맨틱 헤더, 첫 화면, 서비스 소개, Contact us 안내, 네이티브 안내 대화상자
- `styles.css`: 네이비·청록색 디자인, 반응형 배치, 키보드 포커스, 한 번의 등장 효과 및 모션 감소 대응
- `app.js`: 회사 소개·서비스 연결 안내창, 포커스 순환과 복귀
- `theme.js`: 첫 화면 표시 전 테마 적용, 시스템 색상 설정 대응, 테마 선택 저장
- `scripts/server.mjs`: Node.js 기본 모듈 기반 로컬 정적 서버
- `scripts/build.mjs`: 공개 페이지와 에셋만 `dist/`로 복사

첫 범위가 소개 중심의 정적 페이지이므로 프레임워크와 외부 패키지 없이 HTML·CSS·JavaScript를 사용했습니다. 외부 웹폰트 요청 없이 시스템 한글 폰트로 표시하며, Noto Sans KR이 설치된 환경에서는 우선 적용됩니다. 기존 `design/` 자료와 로고 파일은 변경하지 않았습니다. 앱은 프리뷰 iframe이나 대화 환경 API에 의존하지 않습니다.

Headless Edge의 320px, 390px, 1024px, 1440px 렌더링으로 화면을 검수했습니다. 가로 넘침, 로고 로딩, 한글 및 제목 계층, 앵커 대상, 안내창 열기·닫기, Tab/Shift+Tab 포커스 순환·복귀, 모션 감소 설정을 확인했습니다. 빌드 및 JavaScript 구문 검사를 통과했습니다. 실제 모바일 기기와 다른 브라우저의 수동 검수는 추가로 가능합니다.

문의 이메일은 사용자가 제공한 `biz@lightwork.co.kr`을 표시하고 `mailto:` 링크로 메일 앱을 엽니다. 홈페이지 자체의 입력 양식, 전송, 개인정보 수집, 접수 성공 표시는 없습니다. 실제 서비스 URL과 정식 제공 범위는 확인 후 연결합니다.

민원팩토리 아이콘은 기존의 사람·문서·연필 모티프를 네이비·청록색으로 재구성한 `assets/brand/minwon-factory-icon-v2.png`를 사용합니다. 기존 아이콘과 라이트워크 회사 로고는 보존했습니다. [제작 기록과 프롬프트](docs/minwon-icon-design.md)를 참고하세요.

`D:\Minwon_Factory_Migration`의 현재 소스를 읽기 전용으로 분석해 민원 입력, 요지·양식 준비, AI 초안 생성, 검토·내려받기의 네 단계와 법령 참고·이력·통계 소개를 추가했습니다. 개발 중 상태를 표시하며, 코드에 구현된 경로를 서비스 성능이나 출시 보장으로 표현하지 않습니다. 민원팩토리 저장소와 DB는 변경하지 않았습니다.

소개 문구별 소스 근거와 제외한 주장은 [민원팩토리 소개 문구 근거](docs/minwon-content-basis.md)에 기록했습니다. 기존 브랜드 그래픽은 실제 제품 화면이 아닙니다.

### 안내 팝업

‘라이트워크의 생각’ 팝업은 최대 너비 600px로 표시합니다. 모든 안내 팝업에 열기·닫기 애니메이션을 적용하고, 기기의 모션 감소 설정이 켜져 있으면 생략합니다. 모바일 화면에서는 팝업 크기가 화면에 맞춰 줄어듭니다. 팝업을 열어 배경 스크롤을 잠글 때도 스크롤바 공간을 유지하여 본문 좌우 위치가 흔들리지 않도록 합니다.

### 다크 모드

헤더 오른쪽의 달·해 버튼으로 라이트/다크 모드를 전환합니다. 첫 방문에는 기기의 색상 설정을 따르며, 직접 선택한 모드는 브라우저의 `localStorage`에 저장되어 다음 방문에도 적용됩니다. 브라우저 저장소가 차단된 환경에서도 현재 페이지의 전환은 가능합니다. 어두운 배경에서는 기존 흰색 로고 파일을 그대로 사용합니다.

두 모드 모두 320px, 390px, 1024px, 1440px에서 배치와 가로 넘침을 확인했습니다. 테마 전환·선택 저장·다음 페이지 적용, 버튼의 접근성 상태, 로고 표시, 안내창 포커스와 모션 감소 설정을 검수했습니다.

## 첫 개발 범위

1. 헤더: 기존 로고, 회사/서비스 영역으로 이동, 문의 버튼

## 디자인 방향

시안은 사용자가 개발 출발점으로 선택한 초기 방향이며 최종 디자인·문구 확정을 의미하지 않는다.

- 밝고 정돈된 첫 화면 + 네이비 서비스 소개 영역
- 네이비 `#0B2B54`, 청록 `#14B8A6`, 밝은 배경 `#FAFBF8`, 본문 `#132E48`
- 넉넉한 여백, 명료한 한글 타이포그래피, 읽기 쉬운 대비
- 기존 로고 그대로 사용. 넥슨 로고와 닮았다는 이유로 과거 로고를 수정한 이력이 있으므로 임의로 재디자인하지 않는다.
- 폰트는 시안의 Noto Sans KR 참고. 실제 앱에서는 안정적인 대체 폰트를 설정한다.
- 애니메이션은 한 번의 부드러운 등장 정도로 절제하고 `prefers-reduced-motion`을 존중한다.
- 320px, 일반 모바일, 1024px, 넓은 데스크톱에서 확인한다.
- 작은 영문 보조문구는 픽셀 단위 일치보다 가독성과 접근성을 우선해 개선할 수 있다.

## 실제 개발로 옮길 때

- 디자인 원본의 구조와 CSS를 참고해 유지보수 가능한 페이지 또는 컴포넌트로 옮긴다. 독립형 프리뷰의 iframe 래퍼 전체를 프로덕션 앱으로 사용하지 않는다.
- 실제 앱에서는 `window.openai`, `openai:set_globals`, `Tweak` 등 대화 환경에 의존하는 부분을 제거한다.
- `data-lucide` 아이콘은 프리뷰 환경이 초기화한다. 실제 앱에서는 선택한 스택에 맞게 아이콘을 연결한다.
- 기술 스택은 사용자와 확정하지 않았다. 기존 앱이 생겼다면 그 구성을 보존한다. 새 프로젝트라면 두 영역에 맞는 최소 구성을 선택하고 근거를 간단히 설명한다.
- 초기화 시 인계 자료와 사용자 파일을 보존한다. 로그인, DB, 관리자 페이지, 결제, 메일 서버 등을 임의로 추가하지 않는다.
- 이번 인계는 로컬 개발 준비다. 배포, 도메인/DNS 변경, 메일 서비스 변경은 별도 요청 없이 수행하지 않는다.
